# 10 — Backup, restore, and safe reset

**What to build:** A user can export all data, export history for analysis, validate and preview a backup import, and safely recover or reset the app without accidental data loss.

**Blocked by:** 03 — Exercise library management; 04 — Edit future weekly plans; 06 — Detailed set-level training records; 07 — Partial completion, rescheduling, and substitutions; 08 — Goal management; 09 — Adherence and history.

**Status:** ready-for-agent

- [ ] Complete app data can be exported as JSON.
- [ ] Training history can be exported as CSV.
- [ ] Imports are validated and previewed before writing.
- [ ] Import merges by default; replacement requires explicit confirmation.
- [ ] Full reset requires a recent backup and explicit confirmation.
- [ ] Seed initialization never overwrites existing data.
