# 06 — Detailed set-level training records

**What to build:** A user can record detailed training results for a workout, including different values per set and flexible measures for strength, timed, cardio, and bodyweight exercises.

**Blocked by:** 03 — Exercise library management; 05 — Quick workout completion.

**Status:** ready-for-agent

- [ ] A user can add multiple sets to an exercise within a workout session.
- [ ] Each set can record applicable weight, unit, repetitions, duration, distance, quantity, assistance, and notes.
- [ ] Actual values can differ from plan prescriptions such as ranges, failure, or timed targets.
- [ ] A user can edit or delete an erroneous training record with confirmation.
- [ ] Quick-completion records are not treated as measured performance.
