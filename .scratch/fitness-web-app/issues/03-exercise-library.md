# 03 — Exercise library management

**What to build:** A user can inspect the exercise library, create and edit custom exercises, and archive exercises without breaking existing training history.

**Blocked by:** 01 — Protected app foundation and test seam.

**Status:** ready-for-agent

- [ ] Built-in and custom exercises are distinguishable and usable by plans.
- [ ] A user can create and edit exercise name, target part, prescription, and notes.
- [ ] An exercise can be archived instead of hard-deleted.
- [ ] Renaming or archiving preserves stable identity and historical display.
- [ ] Library behavior is covered through the confirmed end-to-end seam.
