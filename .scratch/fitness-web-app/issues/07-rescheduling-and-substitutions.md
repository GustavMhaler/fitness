# 07 — Partial completion, rescheduling, and substitutions

**What to build:** A user can record real-world deviations from a plan: partial completion, explicit skips, make-up training on another date, and exercise substitutions that preserve the planned-to-actual relationship.

**Blocked by:** 04 — Edit future weekly plans; 05 — Quick workout completion; 06 — Detailed set-level training records.

**Status:** ready-for-agent

- [ ] Exercise-level states allow the system to distinguish complete, partial, skipped, and in-progress sessions.
- [ ] A make-up session retains both its planned date and actual date.
- [ ] A user can substitute an actual exercise for a planned exercise.
- [ ] Adherence attributes a substitution to the planned workout while performance remains with the actual exercise.
- [ ] Corrections recalculate affected session and plan statuses.
