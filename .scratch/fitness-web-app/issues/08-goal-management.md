# 08 — Goal management

**What to build:** A user can create, edit, complete, and review simple training goals with text and deadlines.

**Blocked by:** 01 — Protected app foundation and test seam.

**Status:** ready-for-agent

- [ ] A user can create and edit a goal with text, deadline, notes, and achieved state.
- [ ] A user can mark a goal achieved and still view it in history.
- [ ] Goal data leaves room for future type, target value, current value, and unit fields.
- [ ] Goal changes persist across refreshes and devices.
