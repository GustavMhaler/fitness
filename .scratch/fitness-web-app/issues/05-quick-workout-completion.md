# 05 — Quick workout completion

**What to build:** A user can start a workout session from a training day and quickly mark it complete without entering measured exercise results.

**Blocked by:** 02 — First-run initialization and weekly plan display.

**Status:** ready-for-agent

- [ ] A user can start and complete a workout session from the current training day.
- [ ] Quick completion records attendance without inventing weight, repetitions, duration, or distance.
- [ ] A workout session can be in progress, completed, partial, or skipped.
- [ ] Rest days do not require completion and do not count as missed workouts.
- [ ] Repeated completion requests do not create duplicate sessions.
